# When to Stop: Optimal Stopping Games

Three browser games for teaching optimal stopping from *Algorithms to Live By*.

| Game | What changes | Best strategy | Best win rate |
|---|---|---|---|
| One-Way River | The classic: you can only compare | Look at the first 37%, then take the first option better than all of them | About 37% |
| Mango Cart Lane | You know exactly how good each option is | Take the best so far if it clears a bar that drops as options run out | About 58% |
| Project Partner (Level 2) | Half the people you ask say no | Look at the first 25%, then ask everyone who's the best so far | About 25% |

## Play

Open `index.html`, or visit the GitHub Pages site for this repository.

## Files

- `index.html` is the home page that opens each game.
- `games/` holds each game as a single, self-contained HTML file. Each one also works on its own.

No build step or install is needed. Scores are kept only while the page is open.
